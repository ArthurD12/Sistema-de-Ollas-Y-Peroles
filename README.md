# Sistema de Gestión "Ollas y Peroles"

Sistema web de **pedidos rápidos para restaurante**, pensado para restaurantes grandes donde el tiempo entre que el cliente pide y el chef empieza a cocinar importa.

## ¿Qué problema resuelve?

En un restaurante grande, el mozo suele tomar el pedido en papel, caminar hasta la cocina y entregarlo, lo que genera esperas y errores de comunicación.

Con este sistema:

1. El mozo abre la aplicación desde su **móvil**.
2. Ve una pantalla con los **platos disponibles** y toma la orden del cliente.
3. El pedido **llega directamente a cocina**.
4. El chef lo prepara de inmediato, **sin esperar al mozo**.

## Cómo ejecutarlo

1. Clona el repositorio:
   ```bash
   git clone https://github.com/ArthurD12/Sistema-de-Ollas-Y-Peroles.git
   ```
2. Entra a la carpeta del proyecto:
   ```bash
   cd Sistema-de-Ollas-Y-Peroles
   ```
3. Abre el archivo principal dentro de la carpeta `html/` en tu navegador (o sírvelo con una extensión como *Live Server* de VS Code).
